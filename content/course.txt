LESSON 1 1 First programs
SUMMARY main, printf, format specifiers and scanf
# ------------------------------------------------------------
CARD Your first C program
TEXT Every C program starts running at the `main()` function. The line `#include <stdio.h>` gives us the input and output functions, such as `printf`.
TEXT Every statement ends with a semicolon `;` and blocks of code sit inside curly braces `{ }`. C is compiled: your code is turned into machine code before it runs.
TEXT `return 0;` at the end of `main` tells the system that everything worked.
CODE #include <stdio.h>   // gives us printf and scanf
CODE
CODE int main() {
CODE     printf("Hello, World!\n");
CODE     return 0;   // 0 means "everything worked"
CODE }
END
CARD Printing values with printf
TEXT `printf` prints text, and format specifiers say where values go: `%d` for an int, `%f` for a float or double, `%c` for a char and `%s` for a string.
TEXT `%.2f` prints a number with 2 decimal places, and `\n` starts a new line.
CODE int age = 25;
CODE float price = 19.99f;
CODE char grade = 'A';
CODE
CODE printf("Age: %d\n", age);         // Age: 25
CODE printf("Price: %.2f\n", price);   // Price: 19.99
CODE printf("Grade: %c\n", grade);     // Grade: A
END
CARD Reading input with scanf
TEXT `scanf` reads what the user types and stores it in a variable. It needs the variable's address, which is what the `&` means: "address of".
TEXT When reading a single character, put a space before `%c` (as in `" %c"`) so it skips any leftover spaces or new lines.
CODE int age;
CODE char initial;
CODE
CODE printf("Enter your age: ");
CODE scanf("%d", &age);        // & = the address of age
CODE
CODE printf("Enter your initial: ");
CODE scanf(" %c", &initial);   // space before %c skips whitespace
END

EXPLAIN Execution always starts at main(), wherever it is in the file. #include lines are handled before compiling; they don't run.
END

OPTION %f
OPTION %c
OPTION %s
ANSWER 3
EXPLAIN %c is for a char. %d is for an int, %f for a float or double, and %s for a string.
END

EXPLAIN %d is replaced by age (25), and %.2f prints price with exactly 2 decimal places: 19.99. Plain %f would print 19.990000.
END

LESSON 2 1 Variables and maths
SUMMARY Types, const, integer division, remainder and casting
# ------------------------------------------------------------
CARD Variables and types
TEXT In C you must declare the type of every variable before using it. `int` holds whole numbers (usually 4 bytes), `float` and `double` hold decimals (4 and 8 bytes), and `char` holds a single character in single quotes.
TEXT A variable that isn't given a value isn't set to 0: it holds whatever value was already in that memory.
TEXT `const` makes a variable unchangeable. Trying to change it is a compile error.
CODE int var;              // not initialised: whatever was in memory
CODE int age = 25;         // whole number
CODE double pi = 3.14159;  // decimal (8 bytes)
CODE char grade = 'A';     // one character, single quotes
CODE
CODE const int MAX_SCORE = 100;
CODE // MAX_SCORE = 120;   // error: it's const
END
CARD Doing maths
TEXT With two ints, `/` does integer division: the decimal part is cut off, so `10 / 3` is 3. The `%` operator gives the remainder: `10 % 3` is 1.
TEXT `count++` adds 1 and `count--` takes 1 away. `num += 5` is short for `num = num + 5`, and `num *= 2` for `num = num * 2`.
CODE int a = 10, b = 3;
CODE printf("%d\n", a / b);   // 3 (integer division)
CODE printf("%d\n", a % b);   // 1 (remainder)
CODE
CODE int num = 10;
CODE num += 5;    // 15
CODE num *= 2;    // 30
END
CARD Casting
TEXT Casting converts a value to another type. `(float)7 / 2` turns 7 into a float first, so the division keeps its decimal: 3.5.
TEXT Converting a float to an int cuts off the decimal part rather than rounding, so `(int)3.9` is 3.
CODE int result = 7 / 2;            // 3 (truncated)
CODE float exact = (float)7 / 2;    // 3.5
CODE int cut = (int)3.9;            // 3, not 4
END

LESSON 3 1 Decisions and loops
SUMMARY if, else, switch, while, do-while, for, break and continue
# ------------------------------------------------------------
CARD Making decisions
TEXT `if` runs code only when a condition is true. `else if` checks another condition, and `else` catches everything left. Only the first matching branch runs.
TEXT `&&` means AND (both must be true), and `||` means OR (at least one must be true).
CODE int score = 85;
CODE if (score >= 90) {
CODE     printf("Grade: A\n");
CODE } else if (score >= 80) {
CODE     printf("Grade: B\n");    // this one runs
CODE } else {
CODE     printf("Grade: F\n");
CODE }
CODE
CODE if (age >= 18 && age <= 65) printf("Working age\n");
END
CARD The switch statement
TEXT `switch` checks one variable against several exact values. Each `case` needs a `break;` at the end, or the code carries on into the next case (called fall-through).
TEXT Two cases with no code between them share the same code, which is handy for upper and lower case letters. `default` runs when nothing else matches.
CODE switch (grade) {
CODE     case 'A':
CODE     case 'a':
CODE         printf("Excellent!\n");
CODE         break;
CODE     case 'B':
CODE     case 'b':
CODE         printf("Good job!\n");
CODE         break;
CODE     default:
CODE         printf("Invalid grade\n");
CODE }
END
CARD Loops
TEXT A `while` loop checks its condition first, so it may never run. A `do-while` loop checks at the end, so it always runs at least once.
TEXT A `for` loop puts the start, the condition and the step in one line. `break` leaves a loop straight away, and `continue` skips to the next time round.
CODE for (int i = 1; i <= 10; i++) {
CODE     if (i % 2 == 0) {
CODE         continue;   // skip even numbers
CODE     }
CODE     printf("%d ", i);   // 1 3 5 7 9
CODE }
CODE
CODE int number = 3;
CODE do {
CODE     printf("%d ", number);   // 3 2 1
CODE     number--;
CODE } while (number != 0);
END

LESSON 4 1 Arrays and strings
SUMMARY 1D and 2D arrays, sizeof, strings and the null terminator
# ------------------------------------------------------------
CARD Arrays
TEXT An array stores several values of the same type next to each other in memory. Indexes start at 0, so the last element of a 5-element array is index 4.
TEXT If you give fewer values than the size, the rest are set to 0. `sizeof(arr) / sizeof(arr[0])` works out how many elements an array has.
CODE int numbers[5] = {10, 20, 30, 40, 50};
CODE printf("%d\n", numbers[0]);   // 10 (first)
CODE printf("%d\n", numbers[4]);   // 50 (last)
CODE
CODE int scores[10] = {85, 92, 78};   // the rest are 0
CODE int size = sizeof(numbers) / sizeof(numbers[0]);   // 5
END
CARD 2D arrays
TEXT A 2D array is a grid of rows and columns. `matrix[row][col]` picks one element, and nested loops go through every row and column.
CODE int matrix[3][4] = {
CODE     {1, 2, 3, 4},
CODE     {5, 6, 7, 8},
CODE     {9, 10, 11, 12}
CODE };
CODE printf("%d\n", matrix[2][0]);   // 9
CODE
CODE for (int row = 0; row < 3; row++)
CODE     for (int col = 0; col < 4; col++)
CODE         printf("%3d ", matrix[row][col]);
END
CARD Strings
TEXT C has no separate string type. A string is an array of chars that ends with the null terminator `'\0'`. That's how `printf("%s")` knows where it stops: there's no stored length.
TEXT `char name[20] = "Alice";` stores 'A', 'l', 'i', 'c', 'e', '\0'. If you build the array by hand, you must add the `'\0'` yourself.
CODE char name[20] = "Alice";   // '\0' added for you
CODE
CODE int len = 0;
CODE while (name[len] != '\0') {   // count until the terminator
CODE     len++;
CODE }
CODE printf("%d\n", len);   // 5
END

LESSON 5 2 Functions
SUMMARY Writing functions, passing arrays, pass by value and by reference
# ------------------------------------------------------------
CARD Writing a function
TEXT A function is a named block of code you can call again and again. It has a return type, a name and a list of parameters, like `int square(int n)`.
TEXT `return` sends a value back to whoever called it. A function that returns nothing has the return type `void`.
TEXT If a function is written below `main`, put a prototype (just the first line, ending in `;`) above `main` so the compiler knows it exists.
CODE int square(int n);   // prototype
CODE
CODE int main() {
CODE     printf("%d\n", square(4));   // 16
CODE     return 0;
CODE }
CODE
CODE int square(int n) {
CODE     return n * n;
CODE }
END
CARD Pass by value
TEXT When you pass a variable to a function, the function gets a copy of its value. Changing the copy doesn't change the original.
TEXT To let a function change the caller's variable, pass its address with `&` and use `*` inside the function. This is called pass by reference (or pass by pointer). C++ also lets you write `int &x` for the same idea.
CODE void addOne(int x) {
CODE     x = x + 1;      // changes the copy only
CODE }
CODE
CODE void addOneRef(int *x) {
CODE     *x = *x + 1;    // changes the original
CODE }
CODE
CODE int n = 5;
CODE addOne(n);       // n is still 5
CODE addOneRef(&n);   // n is now 6
END
CARD Passing arrays
TEXT An array isn't copied when you pass it. The function gets the address of the first element, so it can change the caller's array.
TEXT Because only the address is passed, the function can't work out the array's length. That's why you pass the size as well.
CODE void doubleAll(int arr[], int size) {
CODE     for (int i = 0; i < size; i++) {
CODE         arr[i] = arr[i] * 2;
CODE     }
CODE }
CODE
CODE int nums[3] = {1, 2, 3};
CODE doubleAll(nums, 3);   // nums is now {2, 4, 6}
END

LESSON 6 2 Number problems
SUMMARY Leap years, palindromes, primes and binary to decimal (Lab 1)
# ------------------------------------------------------------
CARD Leap years and %
TEXT "Divisible by" in C means the remainder is zero: `year % 4 == 0`. Remember `==` compares, while `=` assigns.
TEXT A leap year is divisible by 4, but not by 100, unless it's also divisible by 400. So 2024 is a leap year, 1900 isn't, and 2000 is.
TEXT `bool`, `true` and `false` come from `#include <stdbool.h>`.
CODE #include <stdbool.h>
CODE
CODE bool isLeapYear(int year) {
CODE     return (year % 4 == 0 && year % 100 != 0)
CODE            || year % 400 == 0;
CODE }
CODE
CODE // isLeapYear(2024) -> true
CODE // isLeapYear(1900) -> false
CODE // isLeapYear(2000) -> true
END
CARD Working with digits
TEXT `n % 10` gives the last digit of a number, and `n / 10` removes it. Repeating this goes through the digits from right to left.
TEXT To reverse a number, take the last digit each time and add it on the end of the new number with `reversed * 10 + last`. A palindrome reads the same both ways, so it equals its own reverse, like 121.
CODE int reverse(int n) {
CODE     int reversed = 0;
CODE     while (n != 0) {
CODE         int last = n % 10;               // last digit
CODE         reversed = reversed * 10 + last;
CODE         n = n / 10;                      // drop it
CODE     }
CODE     return reversed;
CODE }
CODE
CODE // reverse(123) -> 321
CODE // palindrome: reverse(n) == n
END
CARD Primes and binary
TEXT A prime is only divisible by 1 and itself. Try dividing by 2, 3, 4 and so on; you only need to go up to the square root, which is what `i * i <= n` checks.
TEXT In binary each digit is worth twice the one to its right: 1, 2, 4, 8. So 110 is 4 + 2 + 0 = 6. Read the digits with `% 10` and double the place value each time.
CODE bool isPrime(int n) {
CODE     if (n < 2) return false;
CODE     for (int i = 2; i * i <= n; i++) {
CODE         if (n % i == 0) return false;
CODE     }
CODE     return true;
CODE }
CODE int binaryToDecimal(int binary) {   // 110 -> 6
CODE     int decimal = 0, place = 1;
CODE     while (binary != 0) {
CODE         decimal += (binary % 10) * place;
CODE         place *= 2;
CODE         binary /= 10;
CODE     }
CODE     return decimal;
CODE }
END

LESSON 7 2 Array problems
SUMMARY Find, insert, delete, reverse, rotate and more (Lab 1)
# ------------------------------------------------------------
CARD Searching an array
TEXT To find a value, check each element in turn. Return its index as soon as you find it, and return -1 at the end if it was never found. -1 works because it can never be a real index.
TEXT Counting how often a value appears is the same loop, but you add 1 to a count instead of returning.
CODE int find(int arr[], int size, int target) {
CODE     for (int i = 0; i < size; i++) {
CODE         if (arr[i] == target) {
CODE             return i;      // found: stop here
CODE         }
CODE     }
CODE     return -1;             // not found
CODE }
CODE
CODE int arr[4] = {7, 3, 9, 3};
CODE find(arr, 4, 3);   // 1 (the first 3)
CODE find(arr, 4, 5);   // -1
END
CARD Inserting and deleting
TEXT An array can't grow, so we keep `size` (how many it can hold) and `count` (how many are in use). Only insert when `count < size`.
TEXT To insert, shift elements one place right, starting from the end so nothing gets overwritten. To delete, shift elements left over the gap, starting from the gap.
CODE // Insert value at index
CODE for (int i = count; i > index; i--) {
CODE     arr[i] = arr[i - 1];
CODE }
CODE arr[index] = value;
CODE count++;
CODE
CODE // Delete the element at index
CODE for (int i = index; i < count - 1; i++) {
CODE     arr[i] = arr[i + 1];
CODE }
CODE count--;
END
CARD Reversing and rotating
TEXT To reverse in place, swap the first and last, then the second and second-last, and so on to the middle. Each swap needs a `temp` variable to hold one value.
TEXT To rotate left by one, save the first element, shift everything left, then put the saved one at the end: {1, 2, 3, 4} becomes {2, 3, 4, 1}.
CODE // Reverse
CODE for (int i = 0; i < size / 2; i++) {
CODE     int temp = arr[i];
CODE     arr[i] = arr[size - 1 - i];
CODE     arr[size - 1 - i] = temp;
CODE }
CODE
CODE // Rotate left by one
CODE int first = arr[0];
CODE for (int i = 0; i < size - 1; i++) {
CODE     arr[i] = arr[i + 1];
CODE }
CODE arr[size - 1] = first;
END

LESSON 9 3 Pointers
SUMMARY Addresses, & and *, pass by pointer, pointer arithmetic, nullptr
# ------------------------------------------------------------
CARD Addresses and pointers
TEXT Every variable lives at an address in memory. `&i` gives the address of `i`.
TEXT A pointer is a variable that stores an address. `int *ptr` is a pointer to an int. `*ptr` means "the value at that address", and you can read it or change it.
TEXT So `ptr` is the address, and `*ptr` is the value stored there.
CODE int i = 5;
CODE int *ptr = &i;          // ptr holds the address of i
CODE
CODE printf("%d\n", *ptr);   // 5: the value at that address
CODE *ptr = 10;              // changes i through the pointer
CODE printf("%d\n", i);      // 10
END
CARD Pass by pointer
TEXT A function normally gets a copy of each argument. If you pass an address instead, the function can use `*` to change the caller's variable.
TEXT That's how `scanf("%d", &age)` works: it's given the address of `age` so it can store the number there.
CODE void setToFive(int *p) {
CODE     *p = 5;          // changes the caller's variable
CODE }
CODE
CODE int main() {
CODE     int i = 3;
CODE     setToFive(&i);   // pass the address of i
CODE     printf("%d\n", i);   // 5
CODE     return 0;
CODE }
END
CARD Pointer arithmetic and NULL
TEXT An array's name is the address of its first element. Adding 1 to a pointer moves it to the next element, not the next byte, so `*(p + 2)` is the same as `p[2]`.
TEXT A pointer that points at nothing should be set to `NULL` in C, or `nullptr` in C++. Check for it before using `*`, because reading through a null pointer crashes the program.
CODE int arr[4] = {10, 20, 30, 40};
CODE int *p = arr;              // same as &arr[0]
CODE
CODE printf("%d\n", *(p + 2));   // 30, same as arr[2]
CODE p++;                        // now points at arr[1]
CODE printf("%d\n", *p);         // 20
CODE
CODE int *nothing = NULL;        // nullptr in C++
CODE if (nothing != NULL) {
CODE     printf("%d\n", *nothing);
CODE }
END

LESSON 10 3 Memory management
SUMMARY Stack and heap, new and delete, malloc and free, leaks
# ------------------------------------------------------------
CARD The stack and the heap
TEXT Ordinary local variables live on the stack. They're removed automatically when their function or block ends, so a pointer to one isn't safe afterwards.
TEXT Memory from `new` lives on the heap. It stays until you give it back with `delete`, so a function can return a pointer to it.
TEXT These lessons use C++, so output uses `cout << x << endl;` instead of `printf`.
CODE int *makeFive() {
CODE     int *x = new int;     // on the heap
CODE     *x = 5;
CODE     return x;             // still there after return
CODE }
CODE
CODE int main() {
CODE     int *p = makeFive();
CODE     cout << *p << endl;   // 5
CODE     delete p;             // give the memory back
CODE }
END
CARD Arrays, malloc and free
TEXT `new int[5]` makes an array on the heap, and it must be freed with `delete[]`, not plain `delete`.
TEXT In C you use `malloc` and `free` instead. `malloc` takes a number of bytes, so multiply by `sizeof`. It returns `NULL` if there's no memory left, so check it.
CODE // C++
CODE int *nums = new int[5];
CODE nums[0] = 7;
CODE delete[] nums;     // [] because it was new[]
CODE
CODE // C
CODE int *vals = malloc(5 * sizeof(int));
CODE if (vals == NULL) {
CODE     printf("Out of memory\n");
CODE     return 1;
CODE }
CODE vals[0] = 7;
CODE free(vals);
END
CARD Leaks and dangling pointers
TEXT A memory leak is heap memory that's never freed and that you've lost the pointer to. The program keeps using more memory the longer it runs.
TEXT A dangling pointer points at memory that's already been freed. Using it gives rubbish or a crash. Setting the pointer to `nullptr` after `delete` stops it being used by mistake.
CODE // Leak: three ints made, only the last freed
CODE int *p;
CODE for (int i = 0; i < 3; i++) {
CODE     p = makeFive();
CODE }
CODE delete p;     // the first two are lost
CODE
CODE // Dangling: avoid by setting to nullptr
CODE int *q = new int(8);
CODE delete q;
CODE q = nullptr;
END

LESSON 11 3 Linked lists
SUMMARY Nodes, inserting, traversing and deleting, doubly linked lists
# ------------------------------------------------------------
CARD Nodes
TEXT A linked list is a chain of nodes. Each node holds some data and a pointer to the next node. The last node's pointer is `nullptr`, which marks the end. We keep a pointer to the first node, called the head.
TEXT To go through a list, start at the head and follow `nextPtr` until you reach `nullptr`. `cur->data` is short for `(*cur).data`.
CODE struct Node {
CODE     int data;
CODE     Node *nextPtr;     // next node, or nullptr at the end
CODE };
CODE
CODE Node *headPtr = nullptr;   // an empty list
CODE
CODE void PrintList(Node *headPtr) {
CODE     Node *cur = headPtr;
CODE     while (cur != nullptr) {
CODE         cout << cur->data << " ";
CODE         cur = cur->nextPtr;
CODE     }
CODE }
END
CARD Adding to the end
TEXT Unlike an array, the nodes can be anywhere in memory, and the list grows one node at a time with `new`.
TEXT To add at the end, make the new node, then walk to the last node and link it on. `InsertAtEnd` takes `Node **` (the address of the head pointer) because if the list is empty, it has to change the head itself.
CODE void InsertAtEnd(Node **ptrToHeadPtr, int newData) {
CODE     Node *newNode = new Node();
CODE     newNode->data = newData;
CODE     newNode->nextPtr = nullptr;
CODE     if (*ptrToHeadPtr == nullptr) {
CODE         *ptrToHeadPtr = newNode;
CODE         return;
CODE     }
CODE     Node *cur = *ptrToHeadPtr;
CODE     while (cur->nextPtr != nullptr) cur = cur->nextPtr;
CODE     cur->nextPtr = newNode;
CODE }
END
CARD Front, delete and doubly linked
TEXT To add at the front, point the new node at the old head, then make it the head. To delete the first node, move the head on first, then delete the old node.
TEXT In a doubly linked list each node also has `prevPtr`, so you can go backwards too.
CODE // Add at the front
CODE Node *n = new Node();
CODE n->data = 5;
CODE n->nextPtr = headPtr;
CODE headPtr = n;
CODE
CODE // Delete the first node
CODE Node *old = headPtr;
CODE headPtr = headPtr->nextPtr;
CODE delete old;
CODE
CODE struct DNode {
CODE     int data;
CODE     DNode *prevPtr;
CODE     DNode *nextPtr;
CODE };
END

# ------------------------------------------------------------
CARD Classes and objects
TEXT A class groups data (fields) and the functions that work on it (methods). Each object, or instance, of the class has its own copy of the fields.
TEXT Fields under `private:` can only be used by the class's own methods. Other code uses public methods such as getters and setters instead.
CODE class Point {
CODE public:
CODE     double getX() { return x; }
CODE     void setX(double newX) { x = newX; }
CODE     void offset(double dx, double dy) {
CODE         x += dx;
CODE         y += dy;
CODE     }
CODE private:
CODE     double x = 0, y = 0;
CODE };
CODE
CODE Point p;
CODE p.setX(2.0);
CODE p.offset(1.0, 1.0);
CODE cout << p.getX();   // 3
END
CARD Constructors
TEXT A constructor has the same name as the class and no return type. It runs when an object is made, to set up its fields. A class can have several, with different parameters.
TEXT A method can be written outside the class using `ClassName::`, which says which class the method belongs to.
CODE class Point {
CODE public:
CODE     Point() { x = 0; y = 0; }      // default
CODE     Point(double px, double py) { x = px; y = py; }
CODE     void print();
CODE private:
CODE     double x, y;
CODE };
CODE
CODE void Point::print() {
CODE     cout << x << ", " << y << endl;
CODE }
CODE
CODE Point a;            // default constructor: 0, 0
CODE Point b(2.0, 3.0);  // 2-parameter constructor
END
CARD Copy constructors and destructors
TEXT A copy constructor runs when an object is made from another, as in `Buffer b2 = b1;`. The default one copies each field, so two objects would share the same array.
TEXT A destructor, `~ClassName()`, runs when an object goes out of scope or is deleted. It's where you free memory the object made with `new`.
CODE class Buffer {
CODE public:
CODE     Buffer(int n) { size = n; data = new int[n]; }
CODE     Buffer(const Buffer &other) {     // copy constructor
CODE         size = other.size;
CODE         data = new int[size];         // its own array
CODE         for (int i = 0; i < size; i++)
CODE             data[i] = other.data[i];
CODE     }
CODE     ~Buffer() { delete[] data; }      // destructor
CODE private:
CODE     int size;
CODE     int *data;
